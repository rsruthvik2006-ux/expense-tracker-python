# Personal Expense Tracker & Analytics Tool

An Object-Oriented Python application for tracking personal financial transactions, categorizing spending, and saving transaction history via CSV persistence.

## Key Features
- **Object-Oriented Design**: Clean encapsulation using `Expense` and `ExpenseTracker` domain models.
- **CSV Data Persistence**: Automatically loads and saves expenses locally to a CSV database file.
- **Categorical Analytics**: Generates real-time financial reporting and spending percentage breakdowns.
- **Zero External Dependencies**: Standard library implementation with no extra package installation required.

## Technical Architecture
- Built with standard library modules: `csv`, `os`, and `datetime`.
- Input parsing and dynamic percentage calculations.
